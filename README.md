# 🤖 AI Code Debugging Agent (LangGraph + LLM)

An intelligent AI-powered debugging assistant that detects, fixes, and explains code errors automatically using **LangGraph + LLMs**.

---

## 🚀 Features

* 🔍 Bug Detection & Auto Fix
* 💬 Chat-based Interface
* 🌐 Multi-language Support
* ⚡ Fast Debugging using LLMs
* 🧠 Context-aware explanations

---

## 🛠️ Tech Stack

* Python
* LangGraph
* LangChain
* LLM (LLaMA / Gemini / Groq)
* HTML / CSS / JS

---

## 📂 Project Structure

```
backend/
frontend/
agent.py
server.py
```

## ⚙️ Setup Instructions

### 1. Clone Repository

```bash
git clone https://github.com/your-username/ai-code-debug-agent.git
cd ai-code-debug-agent
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Add Environment Variables

Create `.env` file:

```
GOOGLE_API_KEY=your_key
GROQ_API_KEY=your_key
```

### 4. Run Project

```bash
python server.py
```

---

## 💡 How It Works

1. User inputs buggy code
2. Agent analyzes using LangGraph
3. LLM detects issue
4. Returns fixed code + explanation
